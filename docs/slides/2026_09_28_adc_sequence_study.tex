\begin{frame}{C5/L2 keeps evaluation and update time}
  \centering

  \slidesource{Saved physical scope records; 16 ADCs per recipe at 1600 MBd}
  \note{These are external COMP and LOGIC edges measured at roughly 160 ps scope sample spacing; channel deskew is not established. Near-zero differences indicate coincidence within that uncertainty. C6/L2 puts LOGIC at COMP fall; C6/L3 leaves only 0.57 ns for the update after LOGIC. This timing comparison suggests a tradeoff, not a proven root cause.}
\end{frame}

\begin{frame}{Matched radix20 output codes at 1600 MBd}
  \centering
  \includegraphics[width=0.98\linewidth,height=0.82\textheight,keepaspectratio]{\analysispath/physical_vs_pex_radix20_codes.pdf}
  \slidesource{Physical ADC01/03; FRIDA-1 one-/two-layer radix20 PEX}

The physical C4/L1 and C7/L3 failures do not appear in the PEX output-code means.}
\end{frame}

\begin{frame}{C5/L2 leads, but no sub-0.5-LSB case is verified}
  \small
  \begin{itemize}
    \item At 1600 MBd, C5/L2 has 14/16 plausible physical ADCs, with two below 1 LSB code sigma; ADC03 still has rare B12 flips and a shifted mean.
    \item None of the eight measured 6/8 recipes combines a plausible code with sigma below 1 LSB. Longer COMP high time alone has not reduced the floor.
    \item PEX passes 48,858/83,300 full timing checks (58.7\%). The matched model precharges its latch, but physical C4/L1 and C7/L3 code failures are absent in PEX.
    \item Silicon latch reset and the physical failure mechanism remain unverified. This scan has no FRIDA-2 physical counterpart.
  \end{itemize}
  \slidesource{29-recipe physical screen; 49-case PEX timing and latch analysis}
\end{frame}
