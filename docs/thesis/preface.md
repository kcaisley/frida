# Preface {#sec-preface .unnumbered}

This is a working draft of a doctoral thesis on compact successive-approximation ADCs for high-frame-rate radiation imaging, developed in the FRIDA project (Fast Radiation Imaging Digitizer Array).

The thesis is written once, in Markdown, and built into two editions: this web page and a PDF typeset with the University of Bonn thesis class.
In the web edition the figures are interactive: hover over a point to identify it, drag to zoom, double-click to reset, and click a legend entry to hide or show a group.
Clicking a point from the ADC survey shows a link to its paper.
The PDF draws the same figures, with the same colours, markers and scales, as vector graphics.

Only the background chapter is drafted so far.
