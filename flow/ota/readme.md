# Status

The operational transconductance amplifier is a block on the [pipeline](../../docs/pipeline.md): `params.py` < `subckt.py` < `sim.py` < `types.py` < `analysis.py` < `plots.py` < `runs.py`, each importing only those before it.

| Netlist generator | ✓ | [subckt.py](subckt.py) | `netlist(Params)` and its nets `Nets`: five-transistor, telescopic, folded-cascode and self-biased amplifiers, NMOS or PMOS input, an optional common-source second stage (its Miller capacitor for simulation only); PDK-compiled devices fingered to the row cells. |
| Netlist tests | ✓ | [test_subckt.py](test_subckt.py) | Mirror polarity, cascode stacks, folding, self-biasing, second stage, the designs the parameters refuse, the runs' designs; every named design compiles in every PDK. | Parameters | ✓ | [params.py](params.py) | `Params` (the design: `Topology`, the input pair's type, the second stage, sizes positive; a self-biased amplifier's input type NMOS and a Miller capacitor only on a second stage, `__post_init__`) and `TbParams`, one testbench run: the PDK, the design, the bench (`Bench`: small-signal, unity-gain step or sine), the supply, the load, the input common mode, the bias current, the cascode biases, the output common-mode target and the feedback's gain, the frequency sweep, the step and the sine. | Testbench generator | ✓ | [sim.py](sim.py) | `testbench(TbParams)`: a balun (the input common mode on both inputs, ±0.5 V AC), bias references (a diode-connected copy of the devices each bias drives, fed their current from a supply of its own, so the supply current is the amplifier's), fixed cascode biases, the loads; a fully differential output adds an ideal common-mode feedback onto the load bias. A differential output would need a common-mode feedback circuit to swing that far: the ideal one diverges. `simulate(tb, run_dir)`: one Spectre run (`+preset=mx`, one thread) left on disk: the small-signal bench's operating point, AC response (`ac`), output noise (`noise`) and transfer functions from every source to `outp` (`xf`: the inputs', so the common mode's, and the supply's, for PSRR and CMRR) on one sweep, in PSF ASCII (Spectre writes a noise analysis whole only so); a unity-gain bench's transient in nutbin, a sample every 5 ps (the step) or 100 ps (the sine). `flow.pipeline.read` reads either as a measurement. |

## How to run

```sh
uv run python -m flow --block ota --run five_t --to results                # characterize one amplifier
uv run python -m flow --block ota --run sizes --to presim                  # the grid, before layout
uv run python -m flow --block ota --run sizes --from results --to results  # its pre-layout records
uv run python -m flow --block ota --run telescopic --to lvs                # one amplifier by ALIGN, without extraction
uv run python -m flow --block ota --run sizes --from table --to table      # the viewer's table
uv run python -m flow --block ota --run five_t --to results --dry-run      # what would run
```

## Design space

- `five_t`, `five_t_pmos`, `telescopic`, `folded`, `self_biased`, `two_stage`: the six amplifiers by name: the five-transistor amplifier with an NMOS and with a PMOS input, the telescopic and the folded cascode, the self-biased complementary amplifier, and a telescopic first stage with common-source second stages (no Miller capacitor).
- `sizes`: each of the six at seven sizings, by name (`sizes(telescopic_w32)`): every width at 8, 16, 32 and 64 units (`w8` to `w64`; `w16` is the named design), the input pair twice as wide (`in_w32`) or twice as long (`in_l4`), and the tail and load at twice their length (`source_l8`).

The differential amplifiers need a common-mode feedback outside the block (vbp sets their output common mode).
