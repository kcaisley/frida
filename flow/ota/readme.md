## How to run

```sh
uv run python -m flow --block ota --run five_t --to results                # characterize one amplifier
uv run python -m flow --block ota --run sizes --to presim                  # the grid, before layout
uv run python -m flow --block ota --run sizes --from results --to results  # its pre-layout records
uv run python -m flow --block ota --run telescopic --to lvs                # one amplifier by ALIGN, without extraction
uv run python -m flow --block ota --run sizes --from table --to table      # the viewer's table
uv run python -m flow --block ota --run five_t --to results --dry-run      # what would run
uv run pytest -m spectre flow/ota/test_sim.py                              # the bias network and the sine's accuracy in Spectre
```

## Design space

- `five_t`, `five_t_pmos`, `telescopic`, `folded`, `self_biased`, `two_stage`: the six amplifiers by name: the five-transistor amplifier with an NMOS and with a PMOS input, the telescopic and the folded cascode, the self-biased complementary amplifier, and a telescopic first stage with common-source second stages (no Miller capacitor).
- `sizes`: each of the six at seven sizings, by name (`sizes(telescopic_w32)`): every width at 8, 16, 32 and 64 units (`w8` to `w64`; `w16` is the named design), the input pair twice as wide (`in_w32`) or twice as long (`in_l4`), and the tail and load at twice their length (`source_l8`).

The differential amplifiers need a common-mode feedback outside the block (vbp sets their output common mode). The self-biased amplifier's tails are biased by its own drains, not by the bench, and are left out of the saturation margins. A two-stage amplifier's second stage pins its first stage's output a V_GS below the supply, which at the lowest supply can put the input cascodes in triode: the saturation margin over the supply reports it.
