# Status

The CDAC is the capacitor array with its drivers: the array's capacitors cannot be characterized for speed without the drivers that switch them. [flow/caparray](../caparray/readme.md) stays the array's generator (weights, layouts, extractions) and [flow/capdriver](../capdriver/readme.md) the drivers' (cells, strengths, and the drives an array's plates call for); this block puts them together and measures how each stage settles. It is on the [pipeline](../../docs/pipeline.md): `params.py` < `subckt.py` < `sim.py` < `types.py` < `analysis.py` < `plots.py` < `sweep.py`, each importing only those before it, and `model.py` above them.
