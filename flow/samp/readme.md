## How to run

```sh
uv run python -m flow --block samp --run scaled --to results                # characterize a grid
uv run python -m flow --block samp --run scaled --from layout --to pex     # lay its designs out, signed off
uv run python -m flow --block samp --run frida1 --to lvs                   # one switch by ALIGN, without extraction
uv run python -m flow --block samp --run scaled --from table --to table    # the viewer's table
uv run python -m flow --block samp --run scaled --to results --dry-run      # what would run
uv run python -m flow --block samp --run frida1 --to postsim                # post-layout, back-annotated
```

## Design space

- `scaled`: each switch 8 to 128 units wide, a quarter to four times FRIDA-1's (`scaled(tgate, mos_w=32, dummy=False)` is FRIDA-1's transmission gate; `tgate` with and without half-size dummies, `nmos`, `pmos`, and the bootstrapped switch by width from 32 units, `scaled(bootstrap_w64)`, its helpers an eighth, none under 4 units, the finest PDK's minimum width, its boost capacitor and its bottom-plate switch's length sized together for the bench's 1 pF or a smaller load: the capacitor twelve times what it shares its charge with, every device on the boosted nodes counted from the netlist, so that V_b' stays above 0.9 V_DD with a third again for the wells and the wiring (Razavi-ADC Eq. (3.70)), the bottom-plate switch the shortest at which the bottom plate cannot pass the output; a switch under 32 units would need a bottom-plate switch with over twice its own gate and is left out).
- `long_channel`: each switch (the PMOS switch too) at twice its length.
- `boost_ladder`: the bootstrapped switch as an on-resistance ladder, the ADC study's samplers (`flow.adc.runs.converters`), each rung by its width: `boost_ladder(w32)`, `w64`, `w112` and `w160`, each sized as `scaled`'s, so every rung is boosted alike.
- `frida1`, `tgate_dummy`, `nmos`, `bootstrap`: the four switches by name, for their layouts (each its hand-written floorplan), not swept apart from their points in `scaled`.

The bootstrap's PMOS n-wells sit on the boosted top plate in the netlist; the layout's row cells put every well on vdd, so its layout needs a separate n-well (flow/layout) before LVS matches.

A bootstrapped switch's gate rises to V_b' above its input as tracking starts, whatever its output: had it risen at once, an output far from the input (a sample far from the previous one) would put V_b' and that distance across the switch's oxide at its output end until the output follows. The gate rides V_b' above the capacitor's bottom plate, so the bottom-plate switch is made long enough that the bottom plate, rising from 0 V, cannot pass the output (where the two meet, the two switches have the same terminal voltages and the long one the smaller current into its node): the gate then stands no more than V_b' above the output. The cost is a slower start, which the acquisition times hold, and a bootstrapping path that follows the input only far below its own corner frequency (Razavi-ADC Eq. (3.79), (3.80)); the on-resistance is the closed switch's, read after a step in mid-track.

Stress. The limit is the kit's nominal supply times its largest corner (110 %): at the highest supply it is the supply itself. Every run saves every device's values, and `terminal_max_v` is the largest pair over all runs but the DAC's (`terminal_max_dac_v`). The full-scale step runs at the nominal and at the highest supply, the converter's own worst case (the output a full scale from the input as tracking starts, the input moving there no faster than a full-scale sine at Nyquist), and the level runs' input moves no faster while the switch holds (its step in mid-track, the switch closed, is a clock edge's: the step response the time constant is read from). Under it the switch's gate stands no more than V_b' above its output, and no device of the pull-down stack has more than a supply across it. At the nominal supply every terminal pair of every device stays within the limit in every run of every bootstrapped size, the complementary clock an edge late included (TSMC65 and IHP130: at most 1.263 V, in the skew run). At the highest supply the pairs that hold a whole supply while the switch holds pass it by what couples onto a node held at a rail, which no sizing here takes to zero (TSMC65 and IHP130, every bootstrapped size): as tracking starts the bottom-plate switch's turn-off kicks the bottom plate below 0 V while the precharge device holds the top plate at the supply (the boost capacitor up to 0.89 mV past in TSMC65, 1.43 mV in IHP130; the gate, which follows the top plate through the precharge device's channel, up to 0.43 and 0.80 mV below 0 V); in IHP130, as holding starts, the complementary clock lifts the top-plate switch's gate control node above the supply until the clock has fallen (up to 3.7 mV, the 32 x 2 switch); and while the input falls at the converter's rate the gate follows it through the switch's overlap and the pull-down's resistance (up to 0.07 mV in TSMC65, 0.16 mV in IHP130). The record's `terminal_max_v` reads that much past the limit at the highest supply. `gate_bulk_max_v` (the boosted gate over the substrate, up to two supplies) is kept apart: under an inverted channel the oxide carries V_GS.
