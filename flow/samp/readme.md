## How to run

```sh
uv run python -m flow --block samp --run scaled --to results                # characterize a grid
uv run python -m flow --block samp --run scaled --from layout --to pex     # lay its designs out, signed off
uv run python -m flow --block samp --run frida1 --to lvs                   # one switch by ALIGN, without extraction
uv run python -m flow --block samp --run scaled --from table --to table    # the viewer's table
uv run python -m flow --block samp --run scaled --to results --dry-run      # what would run
uv run python -m flow --block samp --run frida1 --to postsim                # post-layout, back-annotated
```

## Design space

- `scaled`: each switch 8 to 128 units wide, a quarter to four times FRIDA-1's (`scaled(tgate, mos_w=32, dummy=False)` is FRIDA-1's transmission gate; `tgate` with and without half-size dummies, `nmos`, `pmos`, and the bootstrapped switch by width, `scaled(bootstrap_w64)`, its helpers an eighth, none under 4 units, the finest PDK's minimum width, its boost capacitor 32 times the switch's gate area and 128 times the helpers' width more, so that V_b' stays above 0.9 V_DD for a switch 32 units wide or wider; the narrower ones' longer bottom-plate switch loads the gate more).
- `long_channel`: each switch (the PMOS switch too) at twice its length.
- `boost_ladder`: the bootstrapped switch as an on-resistance ladder, the ADC study's samplers (`flow.adc.runs.converters`), each rung by its width: `boost_ladder(w32)`, `w64`, `w112` and `w160`, the boost capacitor sized as `scaled`'s and the helpers an eighth, so every rung is boosted alike.
- `frida1`, `tgate_dummy`, `nmos`, `bootstrap`: the four switches by name, for their layouts (each its hand-written floorplan), not swept apart from their points in `scaled`.

The bootstrap's PMOS n-wells sit on the boosted top plate in the netlist; the layout's row cells put every well on vdd, so its layout needs a separate n-well (flow/layout) before LVS matches.

A bootstrapped switch's gate rises to V_b' above its input as tracking starts, whatever its output: had it risen at once, an output far from the input (a sample far from the previous one) would put V_b' and that distance across the switch's oxide at its output end until the output follows. The bottom-plate switch's length holds the gate's rise to the output's, at the cost of a slower start: the full-scale step (`acquire`) saves its devices' values, so the record's `terminal_max_v` covers it.
