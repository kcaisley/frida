# Status

| Feature | Status | File | Notes |
|---|---|---|---|
| Netlist generator | ✓ | [subckt.py](subckt.py) | Source followers and flipped voltage followers, NMOS or PMOS input, an optional output sink on a flipped follower. |
| Netlist tests | ✓ | [test_subckt.py](test_subckt.py) | Drain and gate wiring, the flipped follower's feedback, invalid followers. |
| Testbench generator | ✓ | [sim.py](sim.py) | Usb2Phy's `UnityGainTb`: the input a DC level with 1 V of AC, current-reference biases (a diode-connected copy fed 20 µA from a supply of its own), a 100 fF load; or the AC on a test current into the output (1 V through 1 MΩ, DC blocked) for the output impedance. Spectre's `xf` adds the supply's transfer to `vout` (PSRR). A step bench drives the input a quarter of the supply up and back down about its level (slew rates). |
| Simulation runners | ✓ | [sim.py](sim.py) | `follower_characterization`: operating point, AC response and supply transfer of every case at 25 input levels, and a step at its nominal input, from ground to the supply, the AC on the input and on the output, in each PDK about its own core supply (200 runs per PDK, all 1200 in four minutes on 16 workers); `check=True` runs Spectre's static checks at the nominal input. |
| Analysis | ✓ | [analysis.py](analysis.py) | `MeasFollower`; `analyze_follower_transfer` (output level, small-signal gain, −3 dB bandwidth, supply current), `analyze_follower_impedance` (output impedance). In TSMC65 the flipped followers reach 0.3–1.1 kΩ in their working range, the plain ones 2.2–3.6 kΩ; across the PDKs the flipped ones span 60 Ω–1.1 kΩ. `analyze_follower_transfer` also gives the PSRR (input gain over the supply's, at the lowest frequency); `MeasFollowerStep` and `analyze_follower_slew` the output's 10–90 % slew rates, 1 % settling and overshoot on each edge (`slewrate`, `settlingTime`, `overshoot`; run 20261019_003545): a source follower slews fast through its device and at its bias current's I/C the other way (TSMC65 NMOS: +0.72, −0.17 V/ns; 20 µA into 100 fF is 0.2 V/ns), the flipped followers overshoot one edge by up to 29 % (their local loop rings). PSRR at the nominal input: 20–32 dB for an NMOS source follower, 3–8 dB for a PMOS one (its source tracks the supply through its well). |
| Plots | ✓ | [plots.py](plots.py) | One panel per case: transfer and gain, bandwidth and output impedance versus input level, gain and impedance versus frequency at each case's input of highest gain (a fixed share of the supply leaves some PDK's flipped followers outside their range); one figure set per PDK. Run by `python -m flow follower.characterization_study`. PSRR versus input level, step responses with their slew rates. |
| Analysis tests | ✓ | [test_analysis.py](test_analysis.py) | Single-pole responses of known gain, bandwidth, impedance and rejection, a ramped step of known slew and settling; every plot renders. |
| Layout generator | ✓ | [layout.py](layout.py) | Standard-cell rows with cIcCreator, laygo and ALIGN from hand-written floorplans (`design/layout/follower_*.json`). |
| Layout tests | ✓ | [test_layout.py](test_layout.py) | Target registry; every floorplan places each netlist device once and escapes every connected port; every PDK writes every case. |
| Layout runner | ✓ | [layout.py](layout.py) | Four cases in all six PDKs, all 72 layouts DRC clean and LVS correct. A source follower's drain sits on the other type's rail: the row cells tie it in-cell (`rowcell` ties, ALIGN's `far` flag). |
| DRC runner | ✓ | [layout.py](layout.py) | gdscheck and the PDK's DRC for every layout (`row_signoff`). |
| LVS runner | ✓ | [layout.py](layout.py) | The PDK's LVS for every layout against the netlist the build placed. |
| PEX runner | ✗ | - | No extraction. |
