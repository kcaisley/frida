## What it measures, and how

- Delays to q (`delay_rise_s`, `delay_fall_s`): between mid-supply crossings ([Baker] Fig. 10.9, p. 333). A flip-flop's and a divider's run from the clock's capturing edge (clock-to-Q); a latch's from d, which arrives while the latch is open (D-to-Q); an SR latch's from the second active set or reset edge, accepted within that pulse. Medians over the edges that captured, at a 2 ns clock, 50 ps edges and 2 fF on q and qb, at the nominal supply (the supply runs' median); the slowest over the supply runs.
- Captured and held edges: an edge is captured where q moves from the old value to the new one and crosses mid-supply on the way, held where q ends at the value d had before its edge, read 0.05 T before the next opening edge; their shares of the run's edges. A divider's old value is the one its edges set in turn from its first edge after the reset, so a toggle later than the next edge counts as late, not as that edge's capture: q must settle within 0.95 T of its edge.
- Energy per cycle: the charge drawn from V_DD over whole cycles, plus the charge a CMOS driver of each input on V_DD would draw, times V_DD, over the cycles ([Baker] Eq. (11.14) and Eq. (11.15), p. 355); leakage included, d toggling every cycle. A driver draws from V_DD only while its pull-up conducts, so each input source's signed current is integrated from the start of each rising ramp (its mid-supply crossing less half the transition) to the start of the next falling one; what the source takes back as the input falls goes to ground, and the simulator's zero-mean ringing on the source's current cancels.
- Setup and hold, over the data offset (d's crossing before the capturing edge, −100 to 300 ps in 10 ps steps): setup where the run of offsets that capture with both delays within 10 % of those at 300 ps begins, interpolated on the delay between the two offsets that bracket it where the failing one still captured; hold where the run of offsets that keep the old value ends, to one step, negative where d may change before the edge ([Baker] Fig. 13.25, p. 401; Fig. 13.26, p. 402). NaN where the sweep has no boundary.
- f_max, over the clock period (1 ns to 29.4 ps in 10 % steps, the same 3.68 ps edges throughout, a flip-flop's data half a period ahead so that only the cell limits it): f_max ([Razavi-PLL] Sec. 15.1, p. 453), read as the highest frequency below the first one at which not every edge captures, counted from the slowest clock (the block's reading: a pass above a failure does not count). It is a lower bound: f_max lies at or above `fmax_hz` and below the next frequency run, 10 % above it. The share captured at a 1 MHz clock (`captured_1mhz_fraction`) checks a dynamic (TSPC) circuit's lower frequency bound ([Razavi-PLL] Sec. 15.2.2, p. 459).
- Critical charge: a latch holding a 1 is struck on the node then holding 0 (the C2MOS latch's qb with its 2 fF load, the DICE latch's x1) by a double-exponential current of 1 to 208 fC in 10 % steps; the critical charge lies between the largest strike q recovers from (`critical_charge_c`) and the smallest that flips it (`flip_charge_c`). The other storage nodes and the stored 0 are not struck.

## How to run

```sh
uv run python -m flow --block latch --run flop_rst --to results     # characterize one design
uv run python -m flow --block latch --run scaled --to results       # a grid
uv run python -m flow --block latch --run latch_dice --to lvs       # one design by ALIGN, signed off
uv run python -m flow --block latch --run scaled --to results --dry-run
```

## Design space

- `latch`, `latch_rst`, `flop_rst`, `div2`, `flop_tspc`, `div2_tspc`, `latch_dice`, `sr_nand`, `sr_nor`: the nine designs by name.
- `scaled`: each of the nine with every width scaled together, half to four times its own (none under one unit), by its name and scale (`scaled(latch_x2)`).
- `strong_feedback`: each design with feedback devices (the C2MOS designs' feedback inverters, the DICE latch's storage devices) with those alone at twice their width.
- `long_channel`: each of the nine with every device at twice its length.
